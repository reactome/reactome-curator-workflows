# Python dependencies for the Reactome curator workflow skills.
#
# Install (macOS / Linux):
#     pip3 install --user -r requirements.txt
#
# If pip refuses with "externally-managed-environment" (PEP 668 — common with
# Homebrew and uv-managed Pythons), prefer a virtual environment:
#     python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
#     # then run skill scripts with .venv/bin/python3 rather than python3
# Use --break-system-packages only as a last resort: it writes into the
# OS-managed Python and can break system tooling.
#
# Versions are pinned so every curator gets the same set rather than whatever
# PyPI happens to serve that day. Verified 2026-09-02 on macOS (arm64) with
# Python 3.9.6; these releases also support Python 3.10-3.12.
#
# SCOPE: only DIRECT dependencies are pinned here. Their transitive dependencies
# (numpy, cryptography, protobuf, requests, urllib3, ...) still resolve freely.
# For hard reproducibility, capture a full lock from a clean virtual environment
# (NOT `pip freeze --user` — that silently omits anything already satisfied by the
# system site-packages, e.g. six):
#     python3 -m venv /tmp/lockenv
#     /tmp/lockenv/bin/pip install -r requirements.txt
#     /tmp/lockenv/bin/pip freeze > requirements-lock.txt
# and install it with:
#     pip3 install --user --no-deps -r requirements-lock.txt
#
# No PDF library is required — uploaded PDFs are read by Claude directly, not
# via a pypdf-style import.
